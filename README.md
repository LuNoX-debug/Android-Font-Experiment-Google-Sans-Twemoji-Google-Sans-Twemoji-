# Google Sans + Twemoji Android Font

一个融合 Google Sans 与 Twemoji Emoji 的 Android 自定义字体项目。  
A custom Android font project combining Google Sans and Twemoji Emoji.

---

## 简介 | Introduction

本项目尝试将 Google Sans 与 Twemoji Emoji 资源融合，制作一个适用于 Android 系统的自定义字体。

This project attempts to merge Google Sans with Twemoji Emoji resources to create a customized font for Android.

主要目标：
- 使用 Google Sans 提供更统一的英文与数字显示效果
- 使用 Twemoji 提供 Emoji 显示支持
- 探索 Android 字体替换与字体融合方案

Main goals:
- Use Google Sans for a cleaner Latin character and number style
- Add Twemoji Emoji support
- Explore Android font replacement and font fusion methods

## 安装方法 | Installation

### 华为设备 | Huawei Devices

> 以下方法仅适用于华为设备，其他 Android 设备不保证兼容。  
> The following method is only tested on Huawei devices. Compatibility with other Android devices is not guaranteed.

#### 方法 1：使用爱美化 Easy UI Kit

1. 下载并打开 **爱美化 Easy UI Kit - Theme, Font, Icon**
2. 选择：
   - 华为主题
   - TTF 转 HWT 字体
3. 选择本字体文件
4. 生成并应用主题

Steps:
1. Download and open **Easy UI Kit - Theme, Font, Icon**
2. Select:
   - Huawei Theme
   - TTF to HWT Font
3. Choose the font file
4. Generate and apply the theme

---

#### 方法 2：使用 zFont 3

1. 下载并打开 **zFont 3**
2. 进入：
   - Downloads
   - 点击 “+”
   - File
3. 选择字体文件
4. 按软件提示完成安装

Steps:
1. Download and open **zFont 3**
2. Go to:
   - Downloads
   - Tap "+"
   - Select "File"
3. Choose the font file
4. Follow the app instructions to install
